Music Player, saved playlists, installation and file access

Installation: open this bundle from HTTPS or http://localhost, then use Install app in Chrome or Microsoft Edge. The service worker caches the app so it can continue to launch offline after installation.

Saved playlists: playlists are stored locally in IndexedDB. A saved playlist contains its name, track order, file or folder handles, filenames and relative paths. Metadata, duration and bitrate are deliberately read again from the audio files whenever the playlist is opened.

Permissions: the browser may ask you to restore access when a saved playlist is opened. Folder-based playlists normally require one permission per stored root folder. Individually selected files can require permission per file.

Playback: MP3, WAV and FLAC are passed to the browser's native audio engine. Codec support depends on the browser and operating system.

Direct saving: files added with the native file/folder pickers, a supported drag-and-drop operation or Windows file handling can be overwritten after permission is granted. Fallback picker entries without a file-system handle can play, but cannot be reopened automatically from a saved playlist.

Renaming: in-place rename requires a directory handle. This is available for files imported through Add folder or a dropped folder. Otherwise a changed filename is saved through Save As.

File associations: once installed, the PWA registers MP3, WAV, WAVE and FLAC as supported file types. Windows still controls which application is the default for each extension.

Metadata: the app writes common title, artist, album, year/date, track, genre and comment tags. Keep backups before bulk edits.
